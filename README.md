# Impact Compass

Impact Compass is a transparent public-evidence scoring tool for product ideas. It measures demand, pain, momentum, competition fit, activity, channel fit, and evidence quality without making AI verdicts.

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Scripts

```bash
npm test
npm run lint
npm run build
```

## First Slice

- Next.js App Router with TypeScript.
- Deterministic scoring core with unit tests.
- Demo report fixture service.
- Interactive idea brief and query bundle lock flow.
- Seven-pillar Compass graph and Evidence Ledger.

## Trust Rule

The Compass Score measures public evidence only. It is not a prediction of success, willingness to pay, or product quality.
